# תרגול למידת מכונה — Machine-Learning Quiz Game

משחק תרגול (עברית, RTL) לקורס *למידת מכונה*. מציג שאלה אמריקאית עם אפשרויות, בוחרים
תשובה ומקבלים משוב/ציון. אתר **סטטי לחלוטין** (HTML+CSS+JS) — אפשר לפתוח מקומית או
לפרסם ב-GitHub Pages ללא שום שלב בנייה. מבוסס על אותו מבנה כמו אפליקציית *מדעי הנתונים*.

## הפעלה מקומית
פותחים את `index.html` בדפדפן. הנתונים נטענים מ-`questions.js` כמשתנה גלובלי, ולכן זה
עובד גם מ-`file://` (ללא שרת).

## מאפיינים
- **מצב לימוד 📖:** 14 תדריכי מבחן לפי נושא (תרגול לפי נושא), עם הנוסחאות מרונדרות
  כ-MathML, טבלאות, מלכודות ותזכורות. כל מזהה שאלה (למשל `23S-A-Q3`) לחיץ ופותח את
  השאלה עצמה מהמאגר, ומכל פרק אפשר לקפוץ ישר לתרגול הנושא. הנתונים נטענים מ-`learn.js`.
- **מצב בהיר/כהה** (נשמר ב-`localStorage`, ברירת מחדל לפי המערכת).
- **שני מצבי תרגול:** *תרגול חופשי* (משוב מיידי + הסבר) ו-*מבחן מלא* (זמן קצוב, ציון ופירוט).
- **סינון לפי נושא** (13 נושאים) + "רק שאלות שטעיתי בהן".
- **ערבוב סדר התשובות** בכל הצגה (Fisher–Yates) — מנטרל "תמיד ראשונה" של טפסי 0.
- תמיכה במקלדת: `1–8` לבחירה, `Enter`/`←` לשאלה הבאה.

## מקור הנתונים ואיכותם
`questions.js` נבנה אוטומטית מארכיון מבחני הקורס (2022–2026), מבחני לדוגמה ובנק התרגול:
- **363 שאלות** סופיות (לאחר מיזוג כפילויות), **כולן עם תשובה מאומתת** (מחוון רשמי).
- מתוכן **~40 שאלות עם תרשים/גרף** (מטריצת בלבול, עץ החלטה, scatter, K-means, רשת נוירונים,
  לוח שחמט, טבלת אמת) שנחתכו מה-PDF ומחוברות לשאלה ב-`images/exams/`. הכל אומת חזותית.
- מבחן **2025 סמסטר ב׳** (קובץ `.docx` שכולו תמונות) חולץ ב-vision מצילומי המסך (התשובה מסומנת ב-✓).
- **התשובה נגזרה משני מקורות ודאיים בלבד:**
  - **טפסי 0** (`טופס 0` / `form 0`): התשובה הנכונה = **האפשרות הראשונה** (50 שאלות).
  - **קובצי פתרונות** (`פתרונות`/`עם תשובות`/`_sol`): התשובה הנכונה מסומנת ב**מודגש**
    בקובץ; חילצנו זאת מדגלי הפונט (234 שאלות לפני מיזוג).
- **אימות יריב:** כל תשובה נבדקה שוב מול הראיה (מודגש/טופס-0) — **0 אי-התאמות**.
- שאלות התלויות **בתרשים/גרף/מטריצה/נוסחה כתמונה** (≈70) **לא נכללו** — הן מרוכזות
  בקובץ `docs/ASK_ADIR.md` לאישור ידני והוספה מאוחר יותר.
- התשובה נשמרת **לפי תוכן** (לא לפי מיקום), והאפליקציה **מערבבת** את סדר האפשרויות בכל
  הצגה — כך ש"תמיד ללחוץ א" לא עוזר.

פירוט מלא: `tools/build_report.md`, `docs/exam_inventory.md`.

## בנייה מחדש של המאגר (אופציונלי)
```
PYTHONUTF8=1 python tools/extract_exams.py    # PDF/DOCX -> טקסט גולמי (tools/raw/txt/*)
PYTHONUTF8=1 python tools/mark_answers.py      # דגלי מודגש/צבע -> *.marked.txt (זיהוי התשובה)
# מבנה השאלות (tools/raw/<CODE>.json) הופק ע"י סוכני-מודל מהטקסט הגולמי
PYTHONUTF8=1 python tools/build_questions.py   # מיזוג + דדופ -> questions.js/json + build_report.md
PYTHONUTF8=1 python tools/build_learn.py       # docs/briefs/*.md -> learn.js (LaTeX -> MathML)
PYTHONUTF8=1 python tools/validate.py          # בדיקות תקינות
node tools/smoke.js                            # בדיקת נתונים + ערבוב/ניקוד
node tools/verify_dom.js                       # בדיקת רינדור אמיתית (jsdom)
```

## מבנה
```
index.html · styles.css · app.js · questions.js   ← האתר (זה מה שמפרסמים)
learn.js                                          ← מקטע הלימוד (נבנה מ-docs/briefs/)
questions.json                                    ← אותם נתונים, לשימוש חוזר
tools/                                            ← צינור עיבוד הנתונים
docs/briefs/                                      ← 14 תדריכי המבחן (מקור מצב הלימוד)
docs/                                             ← build_plan · exam_inventory · ASK_ADIR
```

> ⚠️ הופק לצורכי לימוד אישי. התשובות אומתו מול מחוונים/טפסי-0, אך מומלץ לאמת מול המקור.
