## 1. מטריצת הבלבול — הבסיס לכל הנושא

```
                          חיזוי המודל
                    Positive      Negative
       Positive  |    TP       |    FN     |   ← כל האמיתיים החיוביים
אמת    Negative  |    FP       |    TN     |   ← כל האמיתיים השליליים
```

> ⚠️ **הדבר הראשון לבדוק בכל שאלה שנותנת מטריצה:** מי השורות ומי העמודות. במאגר **הקונבנציה היא שורות = ערך אמיתי, עמודות = חיזוי** (`SAMP-1-Q3`, `PRAC-X-Q17` שתיהן אומרות זאת במפורש). אם תחליף — תקבל FP במקום FN וכל התשובות יתהפכו.

### ארבעת המדדים

$$\text{Accuracy} = \frac{TP+TN}{TP+FN+FP+TN} \qquad \text{Error rate} = 1 - \text{Accuracy}$$

$$\text{Precision} = \frac{TP}{TP+FP} \qquad \text{Recall} = \frac{TP}{TP+FN} \qquad F_1 = \frac{2 \cdot P \cdot R}{P + R}$$

**איך לזכור מי המכנה:**

| | המכנה | השאלה שהוא עונה עליה |
|---|---|---|
| **Precision** | כל מה שהמודל **אמר** שהוא חיובי (עמודה) | "מבין מה שסימנתי — כמה צדקתי?" |
| **Recall** | כל מה שבאמת חיובי (שורה) | "מבין מה שקיים — כמה תפסתי?" |

> 💡 **PRecision ← FP · REcall ← FN.** Precision נפגע מ-**F**alse **P**ositives, Recall נפגע מ-**F**alse **N**egatives. זו כל ההבחנה, והמבחן בודק אותה שוב ושוב.

### איך לקרוא את הניסוח המילולי

כל שאלות המילים במאגר בנויות מאותן ארבע שורות. תרגם אותן ישירות:

| מה שכתוב בשאלה | לאן זה הולך |
|---|---|
| "ישנם **N** דוגמאות ממחלקה X" | $TP + FN = N$ |
| "מתוכם המודל זיהה **k** נכון" | $TP = k$ ← ולכן $FN = N-k$ |
| "המודל טעה וסיווג **m** מהאחרים כ-X" | $FP = m$ |
| "המודל צדק עבור **שאר** האחרים" | $TN = (\text{סה"כ}) - N - m$ |

## 4. Multi-class — macro, micro, ו-accuracy

שבע שאלות. הניסוח תמיד: *"יש להתייחס לבעיה כבעיית multi-class למרות שישנן שתי מחלקות, כיוון שהמחלקות בעלות חשיבות זהה."*

**מה זה משנה:** ב-multi-class מחשבים precision ו-recall **לכל מחלקה בנפרד**, ואז ממצעים.

### הפרוצדורה — ארבעה שלבים

```
1. בנה מטריצת בלבול 2×2 רגילה: TP, FN, FP, TN
2. מחלקה 1 (ה"חיובית"):  P1 = TP/(TP+FP)      R1 = TP/(TP+FN)
3. מחלקה 2 (ה"שלילית"):  P2 = TN/(TN+FN)      R2 = TN/(TN+FP)
      ← שים לב! עבור מחלקה 2, ה-FN של מחלקה 1 הופך ל-FP שלה, ולהיפך
4. Macro-Precision = (P1+P2)/2      Macro-Recall = (R1+R2)/2
```

> ### 🔑 הזהות שחייבים לדעת
>
> בבעיית multi-class עם **חיזוי יחיד לכל דוגמה**:
>
> $$\textbf{micro-precision} = \textbf{micro-recall} = \textbf{accuracy}$$
>
> זו בדיוק התשובה ל-`25B-A-Q14`. אם אופציה אומרת "ה-accuracy גבוה מה-micro-precision" — היא **שגויה בהגדרה**.

### שבע השאלות, מלאות

|---|---|---|---|---|---|
| `24B-A-Q9` (270) | 135·15·45·75 | 77.8% | 79.2% | 76.25% | **accuracy ≈ 77%** ⚠️ ראה למטה |
| `24B-C-Q6` (200) | 95·20·25·60 | 77.5% | 77.1% | **76.6%** | **macro-recall ≈ 76.6%** |

## 5. hold-out מול k-fold — 14 שאלות, כלל אחד

זה האשכול הגדול ביותר בנושא, והוא **נקודות חינם**. הכל תלוי במשפט אחד:

> ### 🔑 **הרבה דוגמאות ← hold-out · מעט דוגמאות ← k-fold cross validation**

**למה:** hold-out מקריב חלק מהנתונים לקבוצת התיקוף. כשיש המון דוגמאות זה לא כואב, וזה זול חישובית. כשיש מעט — אתה לא יכול להרשות לעצמך, ו-k-fold **מנצל כל דוגמה גם לאימון וגם לתיקוף**.

| | **Hold-out** | **K-fold Cross Validation** |
|---|---|---|
| מתי | **הרבה** דוגמאות | **מעט** דוגמאות |
| עלות חישובית | זולה — אימון אחד | יקרה — K אימונים |
| למה משמש (במאגר) | hyperparameter tuning · שיערוך מודל · model selection | model selection · post-pruning · הימנעות מ-overfitting |

### כל 14 השאלות

| שאלה | הניסוח | ✅ התשובה |
|---|---|---|
| `22B-A-Q16` | מתי k-fold? | model selection **ואין** מספר רב של דוגמאות |
| `22B-C-Q16` | מתי hold-out? | model selection **ויש** מספר רב של דוגמאות |
| `23B-A-Q19` | מתי k-fold? | **post-pruning** לעץ החלטה, ואין הרבה דוגמאות |
| `23B-B-Q19` | מתי hold-out? | **הרבה** דוגמאות + hyperparameter tuning |
| `23S-A-Q13` | מתי hold-out? | **הרבה** דוגמאות + hyperparameter tuning |
| `24B-A-Q2` · `24B-C-Q3` · `24S-A-Q4` · `26B-A-Q17` | מעט נתונים, למנוע overfitting | **k-fold**, כדי לנצל את כל הנתונים |
| `SAMP-2-Q21` · `SAMP-3-Q21` · `PRAC-X-Q24` | dataset ענק | **hold-out** |
| `25B-A-Q12` | K=5 על 1000 דוגמאות | **200 בכל fold; כל דוגמה באימון 4 פעמים ← 800 באימון** |

> ⚠️ **`22B-A-Q16` מול `22B-C-Q16`** — אותן ארבע אופציות, אותו ניסוח, רק המילה `k-fold`/`hold out` מתחלפת בשאלה. התשובה מתהפכת מ-**"אין** מספר רב" ל-**"יש** מספר רב". קרא את השאלה, לא את האופציות.

> ⚠️ **`23B-A-Q19` מול `23B-B-Q19`** — אותו זוג בדיוק, במועד א׳ ומועד ב׳ של 2023. **k-fold ← post-pruning + מעט. hold-out ← הרבה + hyperparameter tuning.** שתי האופציות מוצעות בשתי השאלות.

### `25B-A-Q12` — החישוב היחיד באשכול

K=5, 1000 דוגמאות:
- כל fold = $1000/5 = \mathbf{200}$ דוגמאות
- בכל איטרציה: fold אחד לתיקוף, **4 folds לאימון** ← $4 \times 200 = \mathbf{800}$ באימון
- כל דוגמה משמשת **פעם אחת** לתיקוף ו-**4 פעמים** לאימון

> 🪤 המסיח מחליף בין "4 פעמים באימון" ל-"4 פעמים בתיקוף". **תיקוף = פעם אחת. אימון = K−1 פעמים.**

### `SAMP-1-Q10` — למה **לא** משמש ה-validation set

> **לא משתמשים בו כדי לאמן מודל.** האימון מתבצע על ה-train set בלבד.

הוא **כן** משמש ל: בחירת היפר-פרמטרים · post-pruning · שיערוך/בחירת מודל. שלוש האופציות האלה נכונות ולכן הן לא התשובה.

### `SAMP-2-Q4` / `SAMP-3-Q4` — תכונות של test set טוב

**גם א׳ וגם ב׳:** גדול מספיק כדי להניב תוצאות משמעותיות **וגם** מייצג את מערך הנתונים בכללותו.

## 6. מדדי רגרסיה

### 6.1 ⭐ שאלת "מי בנה מודל טוב יותר" — 3 מועדים

`23S-A-Q18` · `24B-A-Q16` · `SAMP-1-Q22` — ארבעה אנשים, ארבעה ציונים, "מי טוב יותר?"

> ### התשובה תמיד: **זה עם הציון הנמוך ביותר, בהנחה שהמדד הוא RMSE.**

**למה:** RMSE הוא **מדד שגיאה** ← נמוך יותר = טוב יותר. כל שאר האופציות מציעות את הציון הגבוה עם מדד שבו גבוה = טוב (R²), או מדד שכלל לא מתאים.

| שאלה | הציונים | ✅ הזוכה |
|---|---|---|
| `23S-A-Q18` | מריו 0.91 · איבנז 0.90 · גוסטו 0.85 · **פליפו 0.77** | **פליפו — RMSE** |
| `24B-A-Q16` | אילון 0.81 · ג׳ף 0.80 · ברנאר 0.75 · **ביל 0.67** | **ביל — RMSE** |
| `SAMP-1-Q22` | טינקרבל 0.91 · כרים 0.90 · עבדול 0.85 · **ג׳אבר 0.77** | **ג׳אבר — RMSE** |

> 🪤 ב-`SAMP-1-Q22` מוצעת האופציה **"טינקרבל, בהנחה שהמדד הוא accuracy"** — accuracy **אינו מדד לרגרסיה** בכלל. פסילה מיידית.
> 🪤 בכל שלוש השאלות יש אופציה **"בהנחה שהוא טיפל בכפילויות בצורה מיטבית"** — לא קשור לנתונים, תמיד שגוי.

### 6.2 `25B-A-Q3` — חישוב MAE

ערכי אמת: 8, 10, 12 · חיזוי: 8.1, 9.8, 12

$$MAE = \frac{|8-8.1| + |10-9.8| + |12-12|}{3} = \frac{0.1+0.2+0}{3} = \frac{0.3}{3} = \mathbf{0.1}$$

**במיליוני דולרים ← טעות ממוצעת של $100,000.**

> 🪤 **MAE לעולם אינו שלילי** — יש ערך מוחלט. שתי אופציות מציעות `-0.1` ו-`-0.0333`. פסילה מיידית.
> 🪤 `MAE=0.2, הטעות המקסימלית` — MAE הוא **ממוצע**, לא מקסימום.

### 6.3 איזה מדד שייך לאיזו בעיה — `SAMP-2-Q3` / `SAMP-3-Q3` / `SAMP-3-Q16`

| מדד | שייך ל |
|---|---|
| **Confusion matrix**, accuracy, precision, recall, F1 | **סיווג** |
| **MSE, RMSE, MAE, R²** | **רגרסיה** |
| **Purity, NMI** (Normalized Mutual Information) | **אשכול** |

- `SAMP-2-Q3`/`SAMP-3-Q3`: "המדדים הנפוצים להערכת מודל **סיווג**" ← **Confusion matrix** (לא "כל התשובות").
- `SAMP-3-Q16`: "מדוע נהוג להשתמש ב-**purity** למודל **רגרסיה**?" ← **התשובה: purity אינו מדד לרגרסיה.** ההנחה בשאלה שגויה. שים לב לצורת השאלה הזו — היא בונה הנחה כוזבת ומצפה שתתקן אותה.
- `25S-A-Q13`: מטריצת בלבול לא רלוונטית ל-**K-Means** כי הוא אלגוריתם **אשכול** (ללא תוויות אמת), בעוד KNN הוא **מסווג**.

## 7. פירוש הפער בין precision ל-recall

`25B-A-Q7` ו-`26B-A-Q6` הן **אותה שאלה עם מספרים הפוכים**. תדע את הכיוון ותקבל את שתיהן.

| שאלה | הנתון | ✅ המשמעות |
|---|---|---|
| `25B-A-Q7` | precision=**0.7**, recall=**0.9** | recall גבוה ← **מזהה כמעט את כל החיוביים**, אבל precision נמוך ← **הרבה false positives** |
| `26B-A-Q6` | precision=**0.96**, recall=**0.6** | precision גבוה ← **מדייק במה שחזה**, אבל recall נמוך ← **הרבה false negatives** |

> ### 🔑 שתי שורות לשנן
> **recall גבוה** = "תפסתי כמעט את כולם" ← מעט FN
> **precision גבוה** = "כמעט לא טעיתי כשסימנתי" ← מעט FP
>
> ולכן: **precision נמוך ← הרבה FP** · **recall נמוך ← הרבה FN**

ארבע האופציות בשתי השאלות הן ארבעת הצירופים של (מזהה/מדייק) × (FP/FN). **התאם את המחצית הראשונה למדד הגבוה, ואת המחצית השנייה למדד הנמוך.**

### `25B-A-Q20` — dataset לא מאוזן

תקלת מנוע ב-**1%** מהמקרים. תמר: accuracy + error rate. יוסי: f1. שחר: precision.

> ✅ **יוסי ושחר צודקים — עדיף precision / recall / f1 כי ה-dataset לא מאוזן.**

**למה:** מודל שאומר "אין תקלה" תמיד מקבל **99% accuracy** ולא שווה כלום. accuracy מטעה כשמחלקה אחת נדירה.

### `25S-A-Q3` — למה F1 עדיף על accuracy

> ✅ **כי הוא מאזן בין precision ל-recall ומתמקד במחלקה החשובה.**

F1 = **ממוצע הרמוני** של precision ו-recall. המסיחים ("פשוט יותר", "מהיר יותר לחישוב") הם רעש.

### `24S-C-Q18` — accuracy = 0

> ✅ **לבחור אלגוריתם אחר ולאמן שוב על כל הדטהסט.**

> 🪤 האופציה **"להפוך את מחלקות הסיווג ולהשתמש במודל כפי שהוא"** מפתה מתמטית (accuracy 0 ← היפוך נותן 1), אבל היא **לא** התשובה לפי המחוון. accuracy אפס מעיד על בעיה מהותית באימון.

## 9. בחירת מאפיינים (Feature Selection)

### `22B-A-Q20` / `22B-C-Q20` — ✅ **כל התשובות נכונות**

3. **שונות שואפת ל-0** ← נסנן (המאפיין קבוע, אין בו מידע)

### `SAMP-1-Q12` — איזו פונקציה **אינה** ל-feature selection

### `SAMP-1-Q19` — ✅ **תשובות א׳ ו-ג׳ נכונות**

| הטענה | |
|---|---|
| א׳ — אם $H(X_1) = 0$ נסנן אותו | ✅ אנטרופיה אפס = **המאפיין קבוע**, אין בו אינפורמציה |
| ג׳ — אם $IG(Y \mid X_1) = 0$ נסנן אותו | ✅ המאפיין **בלתי תלוי** במחלקה |
| ב׳ — אם $H(X_1 \mid X_2) = 0$ נזדקק לשניהם לנאיב בייס | ❌ הפוך — זו **יתירות מלאה**, $X_1$ נקבע לגמרי מ-$X_2$ |

### `SAMP-1-Q16` — פירסון מול קווריאנס

$\text{Pearson}(attr_1, Y) = 0.09$ · $\text{Cov}(attr_2, Y) = 0.9$ ← ✅ **נשאיר את** $attr_2$.

**למה:** פירסון **מנורמל** לטווח $[-1, 1]$, ולכן 0.09 הוא קשר **כמעט אפסי** — חד-משמעית חלש. קווריאנס אינו מנורמל, אבל 0.9 מול קשר אפסי מכריע.

> 🪤 האופציה **"את Y"** — Y היא **המחלקה**, לא מאפיין. אי אפשר "להשאיר" אותה כפיצ׳ר.

### `25S-A-Q16` — Feature Selection מול PCA

> ✅ **Feature Selection בוחר תת-קבוצה של המאפיינים המקוריים · PCA יוצר קומבינציות לינאריות חדשות.**

## 10. PCA

> ### 🔑 שלוש עובדות שמכסות את כל שש השאלות
> 1. **הרכיבים הראשיים אורתוגונליים** זה לזה ← המשתנים החדשים **בלתי מתואמים** (התלות ביניהם שואפת ל-0).
> 2. PCA **יוצר מאפיינים חדשים** (קומבינציות לינאריות), הוא **לא בוחר** מבין הקיימים.

|---|---|

**למה מנרמלים לפני PCA:** PCA מחפש כיווני **שונות מקסימלית**. מאפיין בסקאלה גדולה ישתלט על הרכיב הראשון רק בזכות היחידות שלו. נרמול **אחרי** PCA לא מתקן את זה — הנזק כבר נעשה.

## 12. ערכים חריגים — `SAMP-1-Q5`

הערכים: **11, 27, 35, 51**. שוקלים להוסיף $x_5$.

$$\mu = \frac{11+27+35+51}{4} = \mathbf{31}$$

$$\sigma = \sqrt{\frac{(11{-}31)^2+(27{-}31)^2+(35{-}31)^2+(51{-}31)^2}{4-1}} = \sqrt{\frac{832}{3}} = \mathbf{16.65}$$

$$z(77) = \frac{77-31}{16.65} = \mathbf{2.76} < 3 \quad ← \textbf{נשאיר}$$

✅ **"אם $x_5=77$, נשאיר אותו, כיוון שהוא רחוק פחות מ-3 סטיות תקן מהממוצע."**

> 🚨 **הפרט הקריטי:** התשובה עובדת **רק** עם סטיית תקן **מדגמית** (חלוקה ב-$n-1 = 3$, מקבלים 16.65). עם סטיית תקן **אוכלוסייתית** (חלוקה ב-$n=4$) מקבלים 14.42, ואז $z = 3.19 > 3$ ו**התשובה מתהפכת**. **בקורס הזה — תמיד $n-1$.**

> 🪤 שתי אופציות בנויות מהיגיון **הפוך**: *"נסנן כי הוא רחוק **פחות** מ-2 סטיות"* ו-*"נשאיר כי הוא רחוק **יותר** מ-2 סטיות"*. קרוב ← משאירים. רחוק ← מסננים. אם המשפט אומר את ההפך — פסול בלי לחשב.

## 15. צ׳קליסט לפני המבחן

- [ ] **Precision ← FP · Recall ← FN.** precision נמוך = הרבה false positives
- [ ] תמיד לשרטט TP/FN/FP/TN **לפני** שמחשבים · לבדוק מי השורות ומי העמודות
- [ ] **סט המספרים החוזר: acc 77.8% · prec 75% · rec 90% · macro-P 79.2% · macro-R 76.25%** (5 מועדים)
- [ ] לחשב את **כל** המדדים — המלכודת היא **מספר נכון עם שם שגוי**
- [ ] אופציה בת שני משפטים ← **שניהם** חייבים להיות נכונים
- [ ] multi-class: מחשבים P ו-R **לכל מחלקה**, ואז ממצעים. **micro = accuracy**
- [ ] **מעט נתונים ← k-fold · הרבה נתונים ← hold-out**
- [ ] K-fold: כל דוגמה **פעם אחת** בתיקוף, **$K-1$ פעמים** באימון
- [ ] validation set **לא** משמש לאימון
- [ ] **RMSE/MAE/MSE — נמוך ניצח.** R²/accuracy — גבוה ניצח. accuracy אינו מדד לרגרסיה
- [ ] MAE אף פעם לא שלילי
- [ ] dataset לא מאוזן ← **f1/precision/recall**, לא accuracy
- [ ] היפר-פרמטר = קלט **לפני** האימון · accuracy = תוצאה **אחרי**
- [ ] PCA: רכיבים **אורתוגונליים** · **נרמול ← PCA ← אימון** · הוא **לא** feature selection
- [ ] שונות 0 ← אין מה ל-PCA למקסם
- [ ] סטיית תקן בקורס הזה: **חלוקה ב-$n-1$**
- [ ] purity ← אשכול · MSE ← רגרסיה · confusion matrix ← סיווג
- [ ] MinMax = פונקציית סילום · t-score ← התפלגות z
