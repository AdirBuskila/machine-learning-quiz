## 1. ⭐ סיווג נקודה — 3 שאלות, אותו חישוב

`SAMP-2-Q11` · `SAMP-3-Q11` · `PRAC-X-Q22` — **אותה נקודה, אותם משקולות, שלוש פעמים.**

$$w_1 = 2,\quad w_2 = 3,\quad b = 0 \qquad\text{הנקודה: } (-1,\,-1)$$

$$w \cdot x + b = 2(-1) + 3(-1) + 0 = \mathbf{-5} \;<\; 0$$

> ## ✅ **קטגוריה $-1$.**

> ### 🔑 הכלל — זהה לפרספטרון ב-[[04 - רשתות נוירונים]] §1
> **$w \cdot x + b > 0$ ← מחלקה חיובית. $< 0$ ← מחלקה שלילית.** בדיוק אותו חישוב, שם אחר.
>
> ב-`PRAC-X-Q22` המשקולות ניתנות כ-$w = (0, 2, 3)$ — כלומר **$w_0 = 0$ ראשון**, ואז $2$ ו-$3$. אותה תוצאה: $0 + 2(-1) + 3(-1) = -5$.

🪤 **שני המסיחים בשלוש השאלות:** *"אין מספיק נתונים"* ו-*"אי אפשר לדעת לפי הנתונים"* — **תמיד שגויים.** יש בדיוק את מה שצריך: וקטור משקולות, bias, ונקודה.

---

## 2. הזזת ה-bias — `SAMP-1-Q13`

נתון מישור הסיווג $\;3x_1 + 5x_2 - 8x_3 - 100 = 0\;$ — כלומר $b = -100$.

> ## ✅ **"אם נגדיל את ה-bias ל-0, יותר וקטורים יסווגו כ**חיוביים**, ולכן צפויות **פחות FN**."**

**למה:** $b$ מתווסף לכל $w \cdot x$. הגדלת $b$ מ-$-100$ ל-$0$ **מוסיפה 100 לכל דוגמה** ← יותר דוגמאות חוצות את הסף ← יותר חיזויי "חיובי" ← פחות חיוביים אמיתיים מפוספסים ← **פחות False Negatives** (ובמקביל **יותר FP**).

> ### 🚨 **זו אותה שאלה בדיוק כמו `23S-A-Q15` ו-`24B-C-Q8`** ב-[[04 - רשתות נוירונים]] §6 — **אותו מישור $3x_1 + 5x_2 - 8x_3$**, אותן ארבע אופציות, רק שם קוראים לזה "פרספטרון"/"נוירון sigmoid" וכאן "SVM".
>
> **שלושה מועדים, שלושה נושאים, תשובה אחת: $b \uparrow$ ← חיוביים ← פחות FN.**

🪤 ארבע האופציות הן ארבעת הצירופים של (מגדילים/מקטינים) × (חיוביים/שליליים), וכולן מסתיימות ב-"פחות FN". **רק אחד נכון.**

## 3. וקטורי תמיכה — `SAMP-2-Q12` · `SAMP-3-Q12`

נתונה טבלה עם 8 דוגמאות ומכפילי לגראנז׳ $\lambda_i$. **בשתי השורות הראשונות $\lambda_i = 65.52$, ובשש הנותרות $\lambda_i = 0$.**

> ## ✅ **יש בדיוק 2 וקטורי תמיכה.**

> ### 🔑 ההגדרה, וזו כל השאלה
> **וקטור תמיכה = דוגמה שעבורה מכפיל לגראנז׳ $\lambda_i > 0$.**
>
> דוגמאות עם $\lambda_i = 0$ **אינן** וקטורי תמיכה — הן לא משפיעות על המישור המפריד כלל.

> 💡 **האינטואיציה:** וקטורי התמיכה הם הנקודות ש**נוגעות בשוליים (margin)** ו"מחזיקות" את המישור במקומו. כל שאר הנקודות אפשר להזיז או למחוק — המישור לא יזוז.

🪤 המסיחים: *"8 SV"* (כל הדוגמאות — אז לא היה טעם בשאלה) · *"בין 1 ל-8"* (התחמקות) · *"אין מספיק נתונים"* (יש — עמודת ה-$\lambda$).

## 4. בנק הטענות — ✅ / ❌

| הטענה | |
|---|---|
| SVM מסווג לפי הסימן של $w \cdot x + b$ | ✅ |
| $w \cdot x + b > 0$ ← מחלקה חיובית | ✅ |
| וקטור תמיכה = דוגמה עם $\lambda_i > 0$ | ✅ |
| דוגמאות עם $\lambda_i = 0$ **אינן** משפיעות על המישור | ✅ |
| הגדלת ה-bias ← יותר חיזויים חיוביים ← **פחות FN** | ✅ |
| SVM לומד **מפריד לינארי** (במרחב שאליו העלינו את הנתונים) | ✅ |
| **"אין מספיק נתונים" כשנתונים $w$, $b$ ונקודה** | ❌ יש |
| **כל הדוגמאות הן וקטורי תמיכה** | ❌ רק אלה עם $\lambda>0$ |
| **הקטנת ה-bias ← יותר חיזויים חיוביים** | ❌ הפוך |
